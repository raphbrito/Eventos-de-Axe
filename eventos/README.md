# Modelo de evento

Cada subpasta representa um evento publicado e contém o mesmo pacote visual:

- `index.html`: página pública;
- `dashboard.html`: painel do RSVP;
- `css/`: estrutura visual compartilhada;
- `js/dados-evento.js`: dados, links e identidade do evento;
- `img/`: logos, imagens e favicons exclusivos.

Para criar um evento, copie a pasta `odun-ije-rafael-oxum`, renomeie-a para o novo slug e altere somente `js/dados-evento.js` e os arquivos de `img/`. O dashboard continua usando a API central definida em `assets/js/config.js`.
